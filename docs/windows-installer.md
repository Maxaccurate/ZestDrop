# Windows EXE installer

The EXE is a complete offline installer for the same Windows x64 application as the portable bundles. It includes .NET, Python and the conversion libraries, FFmpeg and 7-Zip. It does not download extra components or add an automatic updater.

## Install and upgrade

Download `ZestDrop-v1.1.0-windows-x64-setup.exe` from the [release](https://github.com/Maxaccurate/ZestDrop/releases/tag/v1.1.0). Run it and follow the wizard. The installer is unsigned, like the portable executable.

- Windows 10 version 1809 or later, with x64 application support.
- Default directory: `%LOCALAPPDATA%\Programs\ZestDrop`.
- Installation is for the current user and does not request administrator privileges.
- The wizard supports English, Simplified Chinese, Traditional Chinese and Arabic. This is separate from the app's English, Simplified Chinese and Arabic interface languages.
- A Start menu shortcut is created. The desktop shortcut is optional and unchecked initially.
- Startup and Explorer integration remain opt-in settings inside the application.
- The complete bundle is installed together, so Office-specific requirements still apply.

Finish running jobs and quit the copy in the installation folder before upgrading or uninstalling it. Running the installer again repairs or replaces the installed application files. The installer remembers its previous directory and shortcut choice. It refuses a nonempty unrelated folder.

When switching from a portable copy, quit that copy and launch the installed copy from the Start menu. Existing settings are shared through `%LOCALAPPDATA%\ZestDrop`. If an Explorer entry still points to the old portable folder, toggle it off and on from the installed copy. The app refreshes an enabled startup path when launched.

## Uninstall

Use Windows **Settings → Apps → Installed apps → ZestDrop → Uninstall**. The uninstaller removes installed files, its shortcuts and Python bytecode caches generated by the installed modules. It removes startup and Explorer commands only when they point to this installation's executable.

Settings and logs in `%LOCALAPPDATA%\ZestDrop`, converted files, and other user-created files are preserved. The installer does not remove another portable copy's registrations or the Windows StartupApproved preference. Untracked files left in the installation folder can keep that folder from being removed.

## Build

Install [Inno Setup](https://jrsoftware.org/isdl.php) (tested with 7.1.0), and prepare a complete app bundle with `build.ps1`. Then run:

```powershell
./package-exe.ps1

# Package a previously validated release without rebuilding its application:
./package-exe.ps1 -BundlePath ./outputs/releases/v1.1.0/stage/ZestDrop `
  -CompilerPath 'C:/Program Files/Inno Setup 7/ISCC.exe' `
  -OutputDirectory ./outputs/installers
```

The wrapper creates a fresh staging directory, excludes development sources/logs/bytecode, validates required runtimes, generates a SHA-256 payload manifest and targeted cache-cleanup rules, and compiles `packaging/ZestDrop.iss` using LZMA2 solid compression. Existing installer output is never overwritten. Keep the manifest with the build records. AppId is stable across versions and must not be changed for upgrades.

The build outputs `ZestDrop-v<version>-windows-x64-setup.exe` and its `.exe.sha256` checksum. Test on a machine without a prior EXE installation using a fresh folder under this repository's `outputs` directory:

```powershell
./outputs/ZestDrop/runtime/python/python.exe ./work/test-installer.py `
  ./outputs/installers/ZestDrop-v1.1.0-windows-x64-setup.exe `
  ./outputs/installers/installer-payload.json `
  ./outputs/installer-test
```

The integration test installs silently in a Unicode path, verifies payload hashes and current-user registration, runs image/audio conversions, verifies upgrade/uninstall guards during a real image job, repairs modified/missing files, checks ownership-aware registry cleanup, uninstalls and reinstalls. It temporarily tests the app's startup and Explorer keys and restores their exact previous contents in `finally`; it refuses to overwrite an existing EXE installation or Start menu folder. UI-driven wizard interaction, other Windows versions and upgrade paths from future releases need separate validation.

The v1.1.0 EXE is 151,348,721 bytes. All 22 lifecycle checks passed; see the [validation record](validation/v1.1.0-installer.json). Its 1,942 application payload files match the previously released ZIP, including the original v1.1.0 application build. The installer was added as a release asset without moving the version tag.
