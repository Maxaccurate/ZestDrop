## ZestDrop v1.2.1

A visual wheel editor with live previews, a clearer way to reopen the welcome window, and more reliable startup-menu state.

### Visual wheel customization

- Open **Settings → Wheel → Customize wheel…** from the tray menu. The list and the actual wheel now appear together.
- Drag list rows to reorder options, use **Move to top / Move up / Move down**, or press **Alt+Up / Alt+Down**. The preview updates immediately and changes save automatically for the next time you open the wheel.
- Click a preview sector to select its list entry. Preview clicks never run a conversion.
- Choose a file category, formats/tools menu, and a concrete single-file or multi-file example. Options shown match that example instead of combining unrelated single/batch menus. Editing one example preserves saved options used by other examples.
- Two-level wheels now honor custom category and child-option order. Click a category to inspect its outer ring.
- The preview reflects the **last-used first** preference, including its ↻ marker. Turn that preference off for a fixed custom order. **Restore default order** resets the selected file category and menu.
- Uses the existing light/dark palette and rounded interface, with English, Simplified Chinese and Arabic layouts.

### Welcome window and startup fixes

- Added **Welcome window…** directly to the first level of the tray menu. It opens even when **Don't show this window at startup** is selected.
- The tray startup checkbox writes the requested state and then displays the state reported by Windows. Failed writes restore the actual state and show a message; stale asynchronous reads cannot undo a newer click.
- Added a direct **Windows startup app settings** entry for cases where Windows has disabled the startup item. The app does not override that system choice.
- CLI help and `--version` now read the application's build version. The online installer shows the size of the actual offline installer rather than a fixed old value.

Finish or cancel jobs and quit the old app before upgrading. Rerun the installer for an installed copy, or extract a portable bundle into a fresh folder and run `ZestDrop.exe` inside `ZestDrop`. Keep its DLLs, `backend` and `runtime` folders together. Settings stay in `%LOCALAPPDATA%\ZestDrop`. If changing from a portable folder to an installed copy, toggle Explorer integration off and on to update its path.

### Validation and limits

250 local automated checks passed: engine 101, tool parameters 44, progress/live wheel 70, UI controls 18, tray/startup 7 and visual editor 10. [Validation record](https://github.com/Maxaccurate/ZestDrop/blob/main/docs/validation/v1.2.1.json). Visual-editor checks cover order persistence, immediate preview/highlight changes, independent file scenarios, restore defaults, recent-first behavior, two-level ordering and all supported categories, with renders in three languages and both themes. Manual isolated UI checks also covered clicking sectors, dragging rows, keyboard reordering, sample switching, opening the welcome window and toggling startup registration.

- Windows 10 version 1809 or later, x64. The app and installers are unsigned.
- Existing conversion engines and Office requirements are unchanged. Layout-preserving Office exports still require the corresponding desktop Office apps; Office automation was not re-tested for this release.
- The Windows 11 modern shell-extension package is not included; Explorer integration uses the classic menu.
- No automatic updater. Comprehensive multi-monitor/DPI combinations and a real Windows sign-in cycle were not manually re-tested.
- Arabic processing-error messages and exported-image text shaping retain the limitations of v1.2.0.
