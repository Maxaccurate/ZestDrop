## ZestDrop v1.2.0

New file types, a command-line tool and smarter watch folders. Most of this release comes from **@MhammedMokhtari** in [PR #2](https://github.com/Maxaccurate/ZestDrop/pull/2). Thank you!

### New file types

ZestDrop now converts these on your PC, with no Office or other software needed:

- **3D models:** GLB, glTF, OBJ (with materials), STL, 3MF, PLY and FBX input. Export to GLB, glTF, OBJ, STL, 3MF and PLY, or render a PNG/JPG preview.
- **CAD drawings:** DWG and DXF to vector SVG or PDF, to PNG/JPG images, or between DWG and DXF.
- **Fonts:** TTF, OTF, WOFF, WOFF2 and EOT.
- **Data files:** JSON, JSON Lines, YAML, TOML, XML, CSV, TSV and vCard.
- **E-books and comics:** open EPUB, KEPUB, MOBI, AZW3, FB2 and CBZ. Save as EPUB, KEPUB, FB2, DOCX, Markdown, HTML or plain text. Markdown and text files can become EPUB books.
- **Subtitles:** SRT, VTT, ASS, SAMI, LRC, TTML, SUB and SCC.
- **Email:** EML and MSG to HTML or plain text.
- **Spreadsheets and documents:** native reading and writing of XLSX, XLS, ODS, DOCX, PPTX, Markdown and HTML. Formulas, sheet references and error cells are kept when converting between spreadsheet formats.
- **Images to SVG:** trace a picture into vector shapes.

### Command line

The new `zestdrop` command converts files from Command Prompt or PowerShell. Run it from the install folder, or add the folder to your PATH.

```
zestdrop convert photo.png --to webp
zestdrop convert ./drawings -r --to pdf -o ./out
zestdrop watch ./inbox --to png
zestdrop formats
```

If you ask for a format a file can't be converted to, it says so and lists the formats that work. Common spellings such as `jpeg` and `tif` are accepted.

### Watch folders

- **Inbox mode:** after a file is processed, the original moves into an `originals` folder, so it is never processed twice.
- Choose a separate output folder, include subfolders, and filter by file name (for example `*.stl, scan_*`).
- New actions for 3D models and CAD drawings.
- A failed file no longer blocks the rest of the queue.

### Fixes

- The "Open with ZestDrop" menu from Explorer follows dark mode and Arabic right-to-left layout. Its submenus open beside it, and it closes when you click outside it or press Esc.
- Settings stay correct when the settings file changes while the app runs.

All four contain the same complete application (1,966 files), including .NET, Python, FFmpeg, 7-Zip and every library needed. The new engines add about 20 MB to the app folder.

For the portable downloads, extract the entire archive and run `ZestDrop.exe` inside the `ZestDrop` folder. Finish or cancel running jobs and quit the old app before upgrading. Rerun the installer to upgrade an installed copy. Settings stay in `%LOCALAPPDATA%\ZestDrop`.

### Requirements and limits

- Windows 10 version 1809 or later, x64. The executable is unsigned, so Windows SmartScreen may warn on first launch.
- The Explorer right-click entry uses the classic menu (on Windows 11, under **Show more options**). The Windows 11 modern-menu entry is not included in this build.
- Layout-preserving Office exports through Word, Excel or PowerPoint still require those desktop apps. Office automation was not re-tested for this release.
- Processing error messages are not yet translated into Arabic; they appear in English.
- Updates are manual; there is no automatic updater.
