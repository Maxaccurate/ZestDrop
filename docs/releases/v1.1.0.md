## ZestDrop v1.1.0

Arabic interface support, an optional sticky wheel, a reorganized rounded tray menu, and more control over your files.

### Arabic and wheel navigation

- Added Arabic alongside English and Simplified Chinese. The welcome window and tray menus support right-to-left layout, including space for checkmarks and submenu arrows.
- Added **Sticky menu (stay open on release)** in the welcome window and **Settings → Wheel**. It keeps an uncommitted wheel open for hovering and clicking. Dropping directly on a valid operation still runs that operation.
- While the wheel is open, **Ctrl** selects tools, **Shift** selects formats, **Tab** switches between them, and **F8/F9** select formats/tools. Clicking the centre also switches modes. Esc or right-click dismisses the wheel.
- Fixed repeated tray-menu refreshes gradually increasing its width.

Thanks to **@MhammedMokhtari** for ZestDrop's first external contribution, [PR #1](https://github.com/Maxaccurate/ZestDrop/pull/1).

### A clearer desktop interface

- Reorganized the tray menu into clipboard and recent results, tasks, automation, settings, and help.
- Rounded menus and submenus, a new icon-and-title header, consistent spacing, and clearer selection states.
- Added **Match Windows**, **Light**, and **Dark** appearance choices.
- **Settings → Wheel → Customize wheel…** lets you arrange operations. The last-used operation can move to the top with a ↻ marker.

### More file tools

- **Location** reads, removes, or replaces a photo or video's location. Enter coordinates or copy the location from another photo. JPEG location edits preserve the compressed image data.
- **Redact PDF** removes content in marked areas and matches of specified text, then fills those areas with black. This removes the underlying content rather than drawing a cover over it.
- Microsoft Store packaging fixes preserve the intended logo assets. GitHub offers a complete offline EXE installer and portable ZIP/7z bundles.

No administrator rights are required. Startup and Explorer integration remain opt-in settings in the app. [Installer SHA-256](https://github.com/Maxaccurate/ZestDrop/releases/download/v1.1.0/ZestDrop-v1.1.0-windows-x64-setup.exe.sha256).

**[7z portable bundle (147.8 MB)](https://github.com/Maxaccurate/ZestDrop/releases/download/v1.1.0/ZestDrop-v1.1.0-windows-x64.7z):** 40.37% smaller than the 247.9 MB ZIP. Both archives contain the same 1,942 files, verified individually with SHA-256. [7z SHA-256](https://github.com/Maxaccurate/ZestDrop/releases/download/v1.1.0/ZestDrop-v1.1.0-windows-x64.7z.sha256).

For the portable downloads, extract the entire `.7z` or `.zip` archive and run `ZestDrop.exe` inside the `ZestDrop` folder. Use [7-Zip](https://www.7-zip.org/) or another compatible tool for 7z files. Keep `backend`, `runtime`, and the DLLs together. All downloads include .NET, Python, FFmpeg, 7-Zip, and the required Python libraries; no additional runtime download is needed.

Finish or cancel existing jobs and quit the old app before upgrading. Rerun the installer to upgrade an installed copy, or extract a portable download into a fresh folder. Settings and logs remain in `%LOCALAPPDATA%\ZestDrop`, including after uninstall. If you move the app folder or switch from portable to installed, toggle the Explorer right-click integration off and on to update its path. See [installer documentation](https://github.com/Maxaccurate/ZestDrop/blob/main/docs/windows-installer.md) for build and uninstall behavior.

### Requirements and limits

- Windows 10 version 1809 or later, x64. The executable is unsigned, so Windows SmartScreen may warn on first launch.
- Layout-preserving Office exports require the corresponding desktop Microsoft Word, Excel, or PowerPoint application. Office automation was not re-tested for this release.
- Arabic support in this release covers the application interface. Arabic backend messages and Arabic text shaping in exported images are not included.
- Multi-monitor and display-scaling combinations still need broader manual testing.
- Updates are manual; there is no automatic updater. PDF compression re-encodes embedded images as JPEG, which does not preserve transparency in those images.

### Validation

467 local automated checks passed: tool parameters, progress and wheel behavior, UI controls, backend conversion/tool fixtures, advanced branches, app-to-engine dispatch, image/media regressions, backend messages/progress, and location/PDF-redaction regressions. Original fixture files were checked for preservation. Office automation and comprehensive multi-monitor/DPI interaction coverage are outside this release's validation.

The added EXE installer passed 22 local lifecycle checks: per-user installation in a Unicode path, all 1,942 payload hashes matching the original ZIP, app conversions, blocking upgrade/uninstall during a real background job, repair, uninstall/reinstall, cache cleanup and preservation of user settings/files and other copies' registry integrations. The installer does not rebuild or change the v1.1.0 application. Interactive wizard operation and other Windows releases were not manually validated. [Installer validation record](https://github.com/Maxaccurate/ZestDrop/blob/main/docs/validation/v1.1.0-installer.json).
