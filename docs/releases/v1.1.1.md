## ZestDrop v1.1.1

A maintenance release: ZestDrop now runs on .NET 10, Arabic gets English instead of Chinese where a translation is missing, and the app no longer reads its settings file many times a second.

### Changes

- **.NET 10.** The app now ships with the .NET 10 runtime (10.0.13). .NET 8, used until now, stops receiving security updates on 10 November 2026.
- **Lighter while idle.** While running, the app read and parsed its settings file 40 times a second to check the sticky-wheel option. Settings are now kept in memory and read again only when the file changes.
- **Arabic.** Text that has no Arabic translation, including processing error messages, appears in English instead of Chinese. The rotation dial's help line is translated.
- **Smaller app folder.** The Windows SDK library (25 MB) is now only included in the Microsoft Store package, the only build that uses it. The app folder no longer contains copies of the source code and test reports; they are on GitHub.
- Two unnecessary media inspections were removed from **Video settings** and **Join audio**, and developer-only preview code was removed from the app.

All four contain the same complete application (1,945 files), including .NET, Python, FFmpeg, 7-Zip and the required Python libraries. The newer .NET runtime is slightly larger than the old one, so the downloads are about the same size as v1.1.0 even though the app folder is smaller.

For the portable downloads, extract the entire archive and run `ZestDrop.exe` inside the `ZestDrop` folder. Windows 11 opens 7z files directly; on Windows 10 use [7-Zip](https://www.7-zip.org/). Finish or cancel running jobs and quit the old app before upgrading. Rerun the installer to upgrade an installed copy. Settings stay in `%LOCALAPPDATA%\ZestDrop`.

### Requirements and limits

- Windows 10 version 1809 or later, x64. The executable is unsigned, so Windows SmartScreen may warn on first launch.
- Layout-preserving Office exports require the corresponding desktop Microsoft Word, Excel, or PowerPoint application. Office automation was not re-tested for this release.
- Processing error messages are not yet translated into Arabic; they appear in English.
- Updates are manual; there is no automatic updater.
